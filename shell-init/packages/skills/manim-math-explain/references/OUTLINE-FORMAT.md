# `outline.md` 格式 spec（Phase 3 必读）

Manim 分镜开发计划。人类可直接改 Markdown。

> ## outline 是节奏 + 数学对象计划，不是动画说明书
>
> 写：场景切分、beat、屏幕上有什么对象、类比道具、竖屏风险  
> 不写：`FadeIn` / `Transform` / `run_time=0.5` / 粒子特效空话  

**双源**：

- `script.md` → 节拍与顺序（不可乱）  
- `xiang.md` / `article.md` → 对象池细节与可上屏信息  

最终 beat 数以场景实现 + `narrations/` 为准；漂移后回写 outline。

## 模板

````markdown
# Math Video Outline

> **视觉气质**：<一词，如 粉笔实验室 / 纸感推导>
> **画幅策略**：双渲染自适应 / 横屏完整+竖屏切片
> **总时长**：约 <T> 分（口播 ~<X> 字）
````

## 字段约定

### 场景 id

小写+连字符：`hook`、`forward-pass`、`grad-one-knob`。  
对应文件：`scenes/01_hook.py`。

### 对象池（必填）

每场列出：

| 类型 | 例子 |
|---|---|
| 角色映射 | 类比物 ↔ 符号 |
| 颜色/形状绑定 | 损失恒为红 |
| 可演变化 | 哪个数会变、箭头指哪 |
| 简化声明 | 本场把三维压成一个旋钮 |

### Beat 行

```
- beat N (~Ts) — 画面：…；口播意图：…
```

| 规则 | 原因 |
|---|---|
| 1 口播 `---` 块 ≈ 1–2 beat | 过碎难做；过粗变 PPT |
| 估时 3–12s | 中文约 4 字/秒 |
| 画面写**对象**不写 API | 留给 SCENE-CRAFT |
| 点名「只动一个量」 | 落实原则 |

### 竖屏风险注记

每场至少一行：公式宽度 / 多栏对比 / 数轴长度是否在 9:16 爆炸。  
双渲染策略下，注记供 `layout_portrait()` 改排布。

## 章节切分启发式

| 场 | 作用 |
|---|---|
| 01 hook | 抛出唯一问题 + 类比入场 |
| 中间场 | 每个推导节拍一场或半场；单场 30–90s |
| 末场 | 公式收束 + 金句 + 下集钩子（可选） |

一集建议 **4–8 场**；更多则考虑拆集。

## 自检 C（outline 完成后必跑）

| # | 项 | 标准 |
|---|---|---|
| C1 | 核心问题与 Checkpoint 0 一致 |
| C2 | 场景顺序跟随 script，无跳步 |
| C3 | 每场有对象池与颜色绑定 |
| C4 | 每场有竖屏风险注记 |
| C5 | beat 画面描述是对象级，无 Manim API |
| C6 | 至少 60% beat 有「可看见的变化」（非纯贴字） |
| C7 | 末场有可复述金句的画面位 |
| C8 | 画幅策略已写明 A 或 B |

fail → 改 outline → 再进 Checkpoint 3。
