# 数学科普「讲香」模型（Phase 1 必读）

把 LLM / 深度学习数学，从「教材腔 / 自嗨推导」打磨成「普通人听得懂、更听得进去」的叙事。  
本文件是 [`jiang-xiang`](../../jiang-xiang/SKILL.md) 的**领域适配版**：保留十指骨架，改写判定标准，并新增「听得懂 / 听得进去」硬清单。

> **使命**：不是把公式讲得更学术，而是让观众在生活经验里**碰到**数学对象，再愿意跟你走完推导。

---

## 0. 与原十指模型的关系

| 原十指 | 数学科普怎么用 | 红线 |
|---|---|---|
| ① 场景化 | 把符号压进日常动作（炒菜调味、爬山找路、调音量） | 类比必须映射到真实数学结构，禁止装饰性比喻 |
| ② 口语化 | 短句、对象感、「你」 | 不把严谨定义口语到错误 |
| ③ 数字化 | 数字先变感受，核心冲击数保留 | **禁止编造**训练规模 / 准确率 |
| ④ 故事化 | 讲「一个参数的一天」「一次前向的旅程」 | 故事服务结构，不编用户好评 |
| ⑤ 素材化 | 优先「可被动画演示的对象」 | 静态截图墙 < 动态变化 |
| ⑥ 比喻化 | **最重要**：结构比喻 > 形象比喻 | 比喻要能撑完整推导，半路崩盘就换 |
| ⑦ 情绪化 | 好奇 / 恍然 / 「原来黑盒里面长这样」 | 禁用假共情开场 |
| ⑧ 金句化 | 可复述的原理句 | 金句不能歪曲定义 |
| ⑨ 冲突化 | 「你以为在学魔法，其实在做减法」 | 反差要真，不制造伪对立 |
| ⑩ 升华化 | 拉到「学习=用误差改自己」这类可迁移认知 | 不升华成空洞励志 |

另增 **⑪ 先直觉后符号**（数学科普专用，见下）。

## 1. 强制工作流（严禁跳过）

### Step 1 冷读与信息补全

提取客观事实：

- 本集要建立的**定义**（符号表）
- **推导步骤**（不可乱序）
- 已知类比 / 教具
- 受众先验（有无导数经验）

缺场景、类比或「一集一问」时：**先问用户 ≥2 个问题**。严禁编造数学事实与虚假数据。

### Step 2 干瘪诊断

对照十指，写出原文最大的三个问题。数学科普常见病灶：

1. 一上来就是符号墙  
2. 有类比但类比映射不到运算步骤  
3. 正确但无冲突 / 无好奇钩子 → 听得懂但听不进去  
4. 只具象不收束 → 热闹完带不走原理  
5. 跳步（「显然」「易得」）

### Step 3 策略选型

| 套餐 | 组合 | 用途 |
|---|---|---|
| 基础 | 场景化 + 口语化 + **⑪先直觉后符号** | 打底，几乎必选 |
| 信任 | 数字化（感受化）+ 素材化（可演） | 有真数 / 可演示时 |
| 心动 | 情绪化（好奇）+ 冲突化 | 开场与转折 |
| 收束 | 金句化 + 升华化 | 结尾带走一句 |

### Step 4 分层创作（双向拉扯）

每个推导块遵守：

```
生活动作 / 直觉画面
    ↓
数学对象出场（仍少符号）
    ↓
只改一个量，看结果变
    ↓
必要时才亮公式（公式是总结，不是开场）
    ↓
升一行：所以「学习/推理/注意力」本质是…
```

**平衡**：只堆炒菜故事会油；只堆公式会空。必须「一个具体动作 ↔ 一层意义」。

### Step 5 输出画布（对用户可见）

每次 Phase 1 汇报用此结构（可写入 `xiang.md` 文首作为元信息）：

```markdown
## 诊断报告
- 核心事实：…
- 目标受众：…
- 本集唯一问题：…
- 三大干瘪痛点：1.… 2.… 3.…

## 策略选型
- 组合：…
- 理由：…

## 香版讲义
（正文）

## 策略复盘表
| 原文片段 | 策略 | 改写后 | 设计意图 |
|---|---|---|---|
```

## 2. ⑪ 先直觉后符号（硬规则）

| 顺序 | 允许 | 禁止 |
|---|---|---|
| 1 | 先问「我们想让结果更好／更接近」 | 先甩 Loss 公式 |
| 2 | 用箭头 / 大小变化表达「梯度方向」 | 先写 ∂L/∂w 再解释 |
| 3 | 公式作为「刚才看见的事情的名字」 | 公式当主角念三遍 |

**判定**：若把所有 LaTeX 遮住，观众是否仍能用手比划出发生了什么？能 → 过；不能 → 重写。

## 3. 自检 A：「听得懂」清单（理解层）

逐项勾选；任一项 fail → 改 `xiang.md`。

| # | 检查项 | 过关标准 |
|---|---|---|
| A1 | 一集一问 | 文首用一句话写出本集问题；文中不旁支出第二条主线 |
| A2 | 符号有入场介绍 | 每个新符号首次出现前有人话定义或角色名 |
| A3 | 映射表完整 | 类比物 ↔ 数学物 一一对应，中途不偷换 |
| A4 | 推导不跳步 | 无「显然」「不难发现」；每步有「因为…所以…」 |
| A5 | 一次一变量 | 同一段落不同时改 ≥2 个关键量却要求观众跟上 |
| A6 | 公式密度 | 连续 3 句里不应超过 1 个未解释符号串 |
| A7 | 错误边界 | 教学简化处有一句「这里我们简化了…」，防 downstream 误解 |
| A8 | 遮罩测试 | 去掉全部公式后，核心机制仍可用日常语言复述 |

## 4. 自检 A+：「听得进去」清单（注意力层）

> **比听得懂更重要。** 听得懂但听不进去 = 打开就划走 = 视频失败。

| # | 检查项 | 过关标准 |
|---|---|---|
| B1 | 3 秒钩子 | 开头不是自我介绍 / 「今天我们来学习」；是悬念、反差或利益 |
| B2 | 好奇负债 | 前 20% 抛出未解问题，中段才兑付 |
| B3 | 冲突点 ≥1 | 至少一处「你以为 X，其实 Y」且 Y 为真洞察 |
| B4 | 对象感 | 「你」密度合理；不是说明书第三人称 |
| B5 | 节奏起伏 | 具象段与抽象段交替；无连续 ≥4 段纯说理 |
| B6 | 可演性 | 每段关键机制都能想象成屏幕上在动的东西（为 Manim 铺路） |
| B7 | 去 AI 味 | 无假共情、无「颠覆认知」、无万能「本质上/底层逻辑」堆砌 |
| B8 | 结尾可复述 | 存在一句金句，路人听完能转述给朋友 |
| B9 | 中段防掉线 | 约 40%–60% 处有小钩子或小冲突，防止中段疲劳 |
| B10 | 不卖惨不卖弄 | 不贬低观众「你肯定不懂」；也不炫技堆术语 |

## 5. 硬性铁律

1. **实事求是**：不编数据、不编论文结论、不夸大「看完就会训练 SOTA」。  
2. **讲香不删芯**：卖点/数学内核不成立时，只优化表达不够 —— 必须提示用户先修内核。  
3. **拒绝黄色平均线**：正确但平淡必须拉成「高低线」（具体 ↔ 意义）。  
4. **类比可否决**：用户不接受的类比必须换，不硬刚。  
5. **计算机无关优先**：能不提框架/API 就不提；本 skill 讲的是数学机制。

## 6. 领域示例（微梯度 / 训练直觉）

**干瘪**：  
「我们用梯度下降更新权重：θ ← θ − η∇L(θ)。」

**香版方向**（示意）：  
先让「菜」差一点盐 → 尝一口（前向）→ 知道偏淡（损失）→ 只拧盐瓶一下（一个参数）→ 再尝 → 盐瓶拧的方向就是梯度告诉你的方向 → 最后才亮出更新式，并金句：「所谓学习，就是根据误差，改自己手上的旋钮。」

复盘时表格必须能指回具体十指动作（场景化 + 冲突化 + ⑪ + 金句化）。
