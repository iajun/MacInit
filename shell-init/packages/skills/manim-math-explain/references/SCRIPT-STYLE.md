# 口播稿风格指南（Phase 2 必读）

把 `xiang.md`（香版讲义）转成「念出来不别扭、跟得上动画」的 `script.md`。  
默认 **B 站知识区**语气；抖音变体见文末。

> **三条底线**（任一不过整稿重写）：
>
> 1. **推导链完整** —— 口播是换说法，不是删步骤  
> 2. **去 AI 味** —— 口播比文字更怕机器腔  
> 3. **保持原文语言** —— 除非用户要求翻译  

数学科普额外底线：

4. **先人话后符号** —— 念名在动画兑现之后，或紧贴动画  
5. **一句一意** —— 与 `---` 节拍对齐，方便 Manim beat  

---

## 最高原则：信息与推导保留

相对 `xiang.md`：

- 允许砍：套话、重复总结、过长铺垫  
- **禁止砍**：定义、中间推导步、限制条件与简化声明、结尾可复述金句  
- 若香版过长：与用户商量拆集，**禁止**私自砍到「只剩结论」

粗检：`script` 字数不宜低于 `xiang` 正文的 ~50%（公式标记不计入）；更重要的是推导步骤逐项对得上。

---

## 形式层：8 条原则

### 1. 口语化

| 书面 | 口播 |
|---|---|
| 综上所述 | 所以你看 |
| 对损失函数求偏导 | 我们看这个误差，对某一个旋钮有多敏感 |
| 参数更新 | 拧一下旋钮 / 改一下分量 |
| 收敛 | 差不多稳下来了 |

念出来若觉得「端着」→ 改。

### 2. 短句：每句 ≤ 20 字（中文）

公式句子可拆成：人话一句 → 「它的名字叫…」一句。

### 3. 第二人称

多用「你 / 我们」。少用「读者应理解」「我们可以定义」。

### 4. 开头钩子（3 秒）

允许：悬念 / 反差 / 「本集只回答一个问题：…」  
禁止：大家好今天来学；在开始前先复习；我知道你很焦虑；颠覆认知。

### 5. 节拍：`---` 分隔

一个聚焦想法 = 一个 `---` 块 = outline 里至少一个 beat。

```markdown
先别看公式。

---

你桌上有三个旋钮：盐、火、时间。

---

菜端上来，咸了。
```

### 6. 数字：感受优先，冲击数保留

「学习率 0.01」→ 先说「每次只拧一点点」；需要时再让数字上屏。

### 7. 不堆结构词 / 万能模板

少用：首先其次最后、说白了、本质上、底层逻辑、赋能。  
数理过渡用：「然后只动这一个」「你看屏幕上」。

### 8. 公式念法

| 好 | 坏 |
|---|---|
| 误差对盐有多敏感——这就是梯度 | 梯度等于损失对参数的偏导数 |
| 新参数 = 老参数减一点点敏感度 | θ ← θ − η∇L |

同一节拍内：最多亮一个主公式；其余用动画表达。

## 风骨层：去 AI 味（口播加强）

禁止：

- 假共情（「你是不是也曾经…」无具体场景）  
- 假深刻排比（「不是 A，而是 B；不是 C，而是 D」连打多轮）  
- 自我标榜（「用大白话彻底讲透」）  
- 空励志升华（与数学机制脱节）

允许：真实冲突、具体场景、干净金句一句见血。

## 平台变体

### B 站（默认，横屏长内容）

- 可稍慢，允许「停一下看屏幕」  
- 单集常 5–15 分钟；中段加小钩子  
- 可轻互动：「弹幕打个『盐』」类（克制用）

### 抖音 / 视频号（竖屏）

- 前 2 秒必须画面+问题同时砸出  
- 单条常 30–90 秒；复杂推导拆系列  
- 口播更短；金句前置或作标题党但**不说谎**  
- 若双发：从长稿抽「钩子+一个推导节拍+金句」成 `script_short.md`，不要把长稿加速念完

## 三层自检 B（script.md 完成后必跑）

### 第一层 · 形式

| # | 项 | 标准 |
|---|---|---|
| F1 | 短句 | 抽样 20 句，≤20 字占比 ≥80% |
| F2 | 节拍 | 有 `---`；每块一个主想法 |
| F3 | 钩子 | 首段非自我介绍 |
| F4 | 人称 | 「你/我们」明显多于「用户/读者」 |
| F5 | 公式念法 | 无人话的裸公式朗读段 |

### 第二层 · 风骨

| # | 项 | 标准 |
|---|---|---|
| G1 | 无假共情 / 颠覆认知套话 |
| G2 | 无「首先其次最后」堆砌 |
| G3 | 冲突或好奇负债至少 1 处 |
| G4 | 结尾有可复述句 |

### 第三层 · 念出来（重要）

出声念开场 30s + 任意中段 30s：

| # | 项 | 标准 |
|---|---|---|
| S1 | 不顺气 / 卡壳的句子已改短 |
| S2 | 需要看屏的地方有口头路标（「看箭头」「看这个数」） |
| S3 | 与 `xiang.md` 推导步骤能勾对 |

**fail → 先改稿再进 Checkpoint 2。**
