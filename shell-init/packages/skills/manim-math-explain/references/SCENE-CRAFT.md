# 场景开发指引（Phase 4 每场必读 · 单一入口）

正在做的是 **Manim 数学讲解视频**，不是课件导出、不是 PPT 翻页。

判断标准：

- 观众感觉数学在**发生**，不是字幕在换  
- 普通人不靠暂停也能跟上「谁在变」  
- 横屏舒服、竖屏不爆版  

---

## Part 0 · 十条原则

### 1. 一集一问
片头问题贯穿；旁支出字幕小字即可，不新开主线。

### 2. 先直觉后符号
人话与类比道具 → 对象运动 → 公式命名。禁止开场公式墙。

### 3. 一次动一个量
同 beat 内只强调一个变化源。其余静默或淡化。

### 4. 动画即证明
「梯度指向变陡方向」要用箭头/坡面演出来，不要只口述。

### 5. 节拍 = beat
`script.md` 的 `---` 块对齐场景推进；可用 `self.next_section` 方便后期剪。

### 6. 对象有角色
颜色与形状绑定语义（损失=红、参数=蓝…），全片不换皮。

### 7. 双画幅同源
同一套数学逻辑；布局走 `layout_landscape` / `layout_portrait`。见 `DUAL-FORMAT.md`。

### 8. 禁公式墙
同时完整显示的独立公式 ≤ 1 个主公式；旧公式缩小/淡出作上下文。

### 9. 讲香不删芯
实现时发现推导跳了 → 加 beat，不靠旁白含糊过去。

### 10. 带走一句
末 beat 金句大字上屏，停留足够口播念完。

## Part 1 · 开工 5 问（写代码前默念）

1. 本 beat **唯一**要让观众看见的变化是什么？  
2. 哪个 mobject 是英雄，哪些必须退下？  
3. 若不加任何文字，动画还能否表意？  
4. 竖屏时英雄放上半还是安全区中部？  
5. 口播哪一句触发这个动画？（对齐 narrations）

## Part 2 · 关系 → 动作决策树

| 内容关系 | 优先动作 |
|---|---|
| 定义出场 | 道具先出现 → 标签淡入 |
| A 导致 B | 箭头生长 / 高亮传导，勿两物同时弹入 |
| 对比 | 左右（横）或上下（竖）分屏，先 A 后 B |
| 累积列表 | **逐项**；旧项变灰 |
| 更新规则 | ReplacementTransform / 数值变动画，强调「减一点」 |
| 空间直觉 | 数轴、平面箭头、简易曲面；慎用难读 3D |
| 收束金句 | 清场 → 一句 → 微停顿 |

找不到内在动作时，才用干净的 FadeIn 兜底 —— 但每场至少 1 个内容驱动动画。

---

## Part 3 · 视觉工具箱（建议，不强制）

- `ValueTracker` + updater：让数「活」  
- `Arrow` / `Vector`：方向即语义  
- `always_redraw`：坡度随参数变  
- `Indicate` /  Circumscribe：口播点名时轻点  
- `MathTex` / `Tex`：公式；竖屏用 `font_size` 降级 + 换行  
- 自写 `Knob` / `ScoreMeter` 等类比道具（放 `scenes/shared`）

**慎用**：无意义粒子、乱闪、每 beat 不同转场炫技。

---

## Part 4 · 时长参考

| 类型 | 建议 |
|---|---|
| 简单入场 | 0.4–0.8s |
| 强调 Indicate | 0.6–1.0s |
| 数值变化看清 | ≥1.2s 或跟口播 |
| 金句停留 | ≥ 口播时长 |
| beat 之间 | `Wait` 对齐气口，勿无固定魔数无视旁白 |

预览用 `-pql`；成片 `-pqh`。

## Part 5 · 反 AI 味 / 反课件味

禁止：

- 整屏 bullet 列表一次弹出  
- 紫粉霓虹科技腔（无主题依据时）  
- 装饰性神经网络点线图（与本集数学无关）  
- Emoji 当图标  
- 「知识卡片」圆角阴影堆料  

鼓励：

- 大留白、少元素、强对比英雄对象  
- 粉笔/纸感/实验室——与 Checkpoint 3 气质一致

## Part 6 · 代码硬规则

1. 每场一个 `Scene` 子类（或 `VoiceoverScene` 若启用）；文件名 `NN_id.py`  
2. 颜色从 `shared/palette.py` 读，禁止场内魔法 hex 散落  
3. 布局通过 `shared/layout.py` 的画幅分支  
4. `narrations/NN_id.txt` 一行一口播块，与 beat 顺序一致  
5. 不在场景里读超大外部数据；教具数据写死在小常量即可  
6. 预览命令写入场景文件顶注释，方便验收  

示例骨架：

```python
# manim -pql scenes/01_hook.py Hook --resolution 1920,1080
# MANIM_FORMAT=portrait manim -pql scenes/01_hook.py Hook

from manim import *
from scenes.shared.palette import C
from scenes.shared.layout import frame_for, place_hero

class Hook(Scene):
    def construct(self):
        fmt = frame_for()  # landscape | portrait
        # ...
```

## Part 7 · 完工自检 D（每场交付前）

| # | 项 | 标准 |

## Part 8 · 常见反馈速查

| 用户说 | 先查 | 最小改法 |
|---|---|---|
| 看不懂 | A 清单 / 一次一变量 | 拆 beat；加道具 |
| 想划走 | 钩子 / 中段冲突 | 改前 5 秒；加反差 |
| 像网课 PPT | 动画即证明 | 把贴字改成 ValueTracker |
| 竖屏太挤 | DUAL-FORMAT | 改 stack；降字号；公式分行 |
| 太快/太慢 | Wait 与口播 | 对 narrations 重估时 |
| 公式看不清 | 字号/对比 | 单公式英雄化 |

先定位层（叙事 / 视觉 / 画幅 / 代码），再改最小切片，不整场重做。
